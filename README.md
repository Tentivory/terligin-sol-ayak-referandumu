# Terliğin Sol Ayak Referandumu

> **Resmi duyuru:** Bu yazılım, evdeki iki terlikten hangisinin *gerçekten* sol ayak olduğunu belirlemek üzere kurulmuş bağımsız, tarafsız ve kimsenin davet etmediği bir yüksek kurulun çalışma yönergesidir.

Bilim insanları yıllardır susuyor. Komşular fısıldaşıyor. Sabah 07:14'te ayağını yanlış terliğe geçiren vatandaşın onuru zedeleniyor. Artık yeter.

## Bu nedir?

`terlik_referandumu.py` çalıştırıldığında:

1. Kurulu toplar (yani `print` eder).
2. Sol ve sağ terliği tanık olarak dinler.
3. Rastgele ama *çok resmi* bir sandık sonucu açıklar.
4. İtiraz hakkını tanır, sonra yok sayar.
5. Kararın kesinleştiğini ilan eder.

Evet, gerçekten çalışır. Hayır, hayatınızı düzeltmez.

## Kurulum

```bash
python3 terlik_referandumu.py
```

Bağımlılık yoktur. Sadece Python 3 ve biraz vicdan yeter. Vicdan yoksa da çalışır; bu yazılım vicdansızlığa karşı toleranslıdır.
